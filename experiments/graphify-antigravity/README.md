# Graphify + Antigravity semantic adapter experiment

Maturity: PROTOTYPE.

Graphify deterministic AST extraction was retained. API-key semantic backends were not used. Two bounded, read-only Antigravity subscription CLI invocations received exact document lists, a strict JSON schema, plan+sandbox execution, ten-minute limits, and local output capture. Only validated fragments and small receipts reached supervising analysis.

Provider-recorded usage: 299,943 input and 83,375 output tokens across two semantic passes; no separately metered API cost is recorded. Fragments added 177 nodes and 100 edges before graph construction.

This establishes an integration path, not completeness. Graph health warnings remained visible and source verification overruled inference.
